# Daily Roman Missal 1.3.1

More room for the readings, with quieter navigation.

- **Full-height reading pages.** Removed the black page-counter/Settings strip,
  giving text 22 more pixels. The crimson ribbon still shows progress, and
  Select remains a shortcut to Settings.
- **A subtle menu divider.** A fine crimson rule separates the Mass readings
  from Day details and Settings.
- **Version in Settings.** A small label at the bottom reads `v1.3.1`. It comes
  from the build metadata and updates automatically with each release.

The divider uses the drawing path verified on PT2 firmware 4.38.4. The startup
fault found during development was corrected before this release.

**Requires Pebble Time 2 (Emery).** Download `daily-roman-missal.pbw` below or use
[Roman Missal in the Pebble App Store](https://apps.repebble.com/9e466762014d4b1ab248219f).

The selected English readings and General Roman Calendar for 2020–2037 are unchanged.
The app remains fully offline. Font and theme choices persist; reading positions
do not. Existing content scope, attribution and privacy terms remain unchanged.

## Verification

Clean SDK build, all four ASan/UBSan host suites, emulator navigation and native
screenshots checked. The corrected UI has been tested on the physical PT2 with
successful launches and reading navigation. Dedicated overnight, disconnected-use
and battery soak remain unmeasured.
